### 🔍 How I test

- **Design first.** Positive and negative cases, boundaries, and the paths real users take.
- **Explore.** Hands-on exploratory and regression testing to find what scripts don't cover.
- **Automate what repeats.** Independent tests, stable locators, no fixed sleeps.
- **Verify the backend too.** UI actions are double-checked against the API or stored data.
- **Make failures easy to read.** Screenshots, traces and step-by-step reports for every failure.
